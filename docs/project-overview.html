FOSIM Project Guide

Fastening Optimization & Simulation Manager

SH-2 Smart Manager 설정값과 Torque/Speed/Angle 파형 CSV를 입력받아 파형 분석, 이상 판정, 실시간 설정 변경 시뮬레이션, 후보 설정 비교를 수행하는 MVP 프로젝트입니다.

CSV 기반 MVP 실제 SH-2 장비 Write 없음
React + FastAPI + SQLite
개요 프로젝트 구조 데이터 흐름 주요 기능 API 입력 데이터 실행/배포 한계와 안전

1. 한눈에 보는 역할

입력Settings + Waveforms

설정 CSV 1개와 파형 CSV 1개 이상을 Import합니다. 여러 파형은 cycle_id별로 분리됩니다.

분석Segments + Features

Engage, Seating, Target, Hold, Stop 지점을 찾고 Overshoot, Clamp Time, Stability 같은 특징값을 계산합니다.

출력Simulation + Candidates

설정 변경 후 예상 파형을 Overlay하고 Quality, Cycle Time, Minimum Change 후보를 비교합니다.

  → predicted_waveform
  → WaveformChart overlay

4. 주요 기능

복수 파형 입력

여러 Waveform CSV 파일을 선택할 수 있고, 백엔드는 각 CSV와 내부 cycle_id를 기준으로 cycles[] 결과를 생성합니다.

CycleSelector

파형 Viewer

현재 Torque, Speed, Angle과 예측 Torque를 같은 Chart에 Overlay합니다. Engage, Seating, Target, Hold, Stop marker를 표시합니다.

WaveformChart

Feature 비교

현재 Feature와 예측 Feature를 나란히 보여주며 Final Torque, Overshoot, Clamp Time, Stability를 상단 KPI로 요약합니다.

FeatureTable

Rule 진단

Overshoot, Undershoot, Clamp/Hold instability 같은 이상 유형을 Feature 기반 규칙으로 판정합니다.

DiagnosisPanel

Live 설정 Editor

Target Speed, Clamp Rising Time, Torque Hold Time, Target Torque를 수정하면 예상 파형을 자동 재계산합니다.

SettingsPanel

후보 설정 추천

Quality stable, Cycle time, Minimum change 세 가지 후보를 생성하고 점수, 예상 Feature, 주의사항을 비교합니다.

5. API와 저장 흐름

Endpoint입력처리출력/저장
GET /api/health-서버 상태 확인{ status: "ok" }
GET /api/sample/cycle-합성 settings/waveform 생성 후 분석단일 sample cycle
POST /api/import/csvsettings_csv, waveform_csvs[]복수 파형 Import, 분석, DB 저장cycle, analysis, cycles[]
POST /api/simulations선택 cycle waveform + current/candidate settingsRule 기반 예상 Feature와 파형 생성SimulationRecord 저장
POST /api/optimizations선택 cycle waveform + objectives후보 생성, 제약 필터, 점수 계산OptimizationRecord 저장

SQLite 저장 테이블

CycleRecord, SettingsRecord, AnalysisRecord, SimulationRecord, OptimizationRecord가 data/sh2_optimizer.db에 저장됩니다.

프론트 상태 중심

useFasteningWorkspace가 Import 결과, 선택 cycle, candidate settings, simulation, optimization 상태를 한 곳에서 관리합니다.

6. 입력 데이터 계약

Settings CSV 필수 컬럼

cycle_id
target_speed
target_torque
clamp_rising_time
torque_hold_time

Settings row가 1개뿐이면 여러 파형에 공유 설정으로 적용하고 warning을 남깁니다. 여러 row가 있으면 waveform cycle_id와 같은 row를 찾습니다.

Waveform CSV 필수 컬럼

cycle_id
sample_index
time_ms
torque

선택 컬럼은 speed, angle, current, event_code입니다. 여러 파일 또는 한 파일 안의 여러 cycle_id 모두 처리 가능합니다.

7. 실행과 배포 방식

개발 실행

cd backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

cd frontend
npm.cmd run dev

Open http://127.0.0.1:5173

Vite dev server는 /api를 http://127.0.0.1:8000으로 proxy합니다.

EXE 배포

powershell -ExecutionPolicy Bypass -File scripts/build_exe.ps1

React build 결과와 FastAPI backend를 PyInstaller로 묶어 FOSIM.exe를 생성합니다. 배포 zip은 releases/ 또는 output 폴더에 보관됩니다.

8. 현재 한계와 안전 메모

중요: 현재 MVP는 CSV 기반 Rule 시뮬레이터입니다. 실제 SH-2 USB/RS485 통신, Smart Manager 자동 제어, 양산 설정 Write, PLC 연동은 포함되어 있지 않습니다. 예측 파형은 설정 변경 방향성을 보기 위한 참고값이며 실제 체결 결과를 보증하지 않습니다.

좋은 사용처

파형 분석 흐름 검토, 설정 변경 영향 교육, CSV 기반 POC, UI/UX 검증.

추가 검증 필요

실제 SH-2 데이터, 동일 조건 before/after 시험, 제품별 허용 토크, 현장 품질 기준.

확장 방향

SEHAN/Modbus 통신, 실험계획 DOE, ML Feature predictor, 승인형 Write/rollback.
