FOSIM Project Guide

Fastening Optimization & Simulation Manager

SH-2 Smart Manager 설정값과 Torque/Speed/Angle 파형 CSV를 분석해 체결 구간, 실용 특징값, 이상 징후, 설정 변경 시뮬레이션, 최적화 후보를 한 화면에서 비교하는 MVP입니다.

React + FastAPI + SQLite
개요 최신 릴리스 구조 데이터 흐름 주요 기능 API 입력 데이터 실행/배포 제한/안전

1. 한눈에 보는 역할

입력 Settings + Waveforms

설정 CSV와 하나 이상의 파형 CSV를 가져옵니다. 여러 파형은 cycle_id 기준으로 분리됩니다.

분석 Segments + Features

Engage, Seating, Target, Hold, Stop 구간을 찾고 overshoot, clamp time, stability 같은 특징값을 계산합니다.

출력 Simulation + Candidates

설정 변경에 따른 예상 파형을 겹쳐 보고 Quality, Cycle Time, Minimum Change 후보를 비교합니다.

4. 전체 데이터 흐름

1. CSV ImportSettings CSV + 하나 이상의 waveform CSV
2. Batch Splitcycle_id 기준으로 파형 분리
3. Analyze전처리, 구간 검출, 특징값 추출
4. Diagnose규칙 기반 이상 유형 판정
5. Simulate변경 설정값으로 예상 파형 생성
6. Optimize제외 cycle을 뺀 기준 파형으로 추천 후보 비교

Import/분석 흐름

ImportPanel
  -> importCsv(settingsCsv, waveformCsvs[])
  -> POST /api/import/csv
  -> import_csv_batch()
  -> preprocess_waveform()
  -> detect_segments()
  -> extract_features()
  -> diagnose()
  -> cycles[] + active_cycle_id 반환

실시간 시뮬레이션 흐름

SettingsPanel value change
  -> useFasteningWorkspace debounce
  -> POST /api/simulations
  -> simulate_waveform()
  -> predicted_features
  -> predicted_waveform
  -> WaveformChart overlay

6. API와 저장 흐름

Endpoint입력처리출력/저장
GET /api/health-서버 상태 확인{ status: "ok" }
GET /api/sample/cycle-합성 settings/waveform 생성 후 분석샘플 cycle과 group summary
POST /api/import/csvsettings_csv, waveform_csvs[]복수 파형 import, 분석, DB 저장, group summary 계산cycles[], active_cycle_id, group_summary
POST /api/simulations선택 cycle waveform + current/candidate settings규칙 기반 예상 feature와 파형 생성SimulationRecord 저장
POST /api/optimizations하나 이상의 waveform + objectives후보 생성, 제약 필터, 점수 계산OptimizationRecord 저장

SQLite 저장 테이블

CycleRecord, SettingsRecord, AnalysisRecord, SimulationRecord, OptimizationRecord가 data/sh2_optimizer.db에 저장됩니다.

프론트 상태 중심

useFasteningWorkspace가 import 결과, 선택 cycle, candidate settings, simulation, optimization, group summary 상태를 한 곳에서 관리합니다. 최적화는 selectOptimizationWaveforms를 통해 제외되지 않은 cycle을 우선 사용합니다.

7. 입력 데이터 계약

Settings CSV 필수 컬럼

cycle_id
target_speed
target_torque
clamp_rising_time
torque_hold_time

Settings row가 하나뿐이면 여러 파형에 공통 설정으로 적용하고 warning을 포함합니다. 여러 row가 있으면 waveform cycle_id와 같은 row를 찾습니다.

Waveform CSV 필수 컬럼

cycle_id
sample_index
time_ms
torque

선택 컬럼은 speed, angle, current, event_code입니다. 여러 파일 또는 한 파일 안의 여러 cycle_id를 처리할 수 있습니다.

8. 실행과 배포 방식

개발 실행

cd backend
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload

cd frontend
npm.cmd install
npm.cmd run dev

Open http://127.0.0.1:5173

Vite dev server는 /api를 http://127.0.0.1:8000으로 proxy합니다.

EXE 빌드와 배포

powershell -ExecutionPolicy Bypass -File scripts/build_exe.ps1

스크립트는 npm install, 프론트 테스트, 프론트 빌드, 백엔드 테스트, PyInstaller 패키징을 순서대로 실행합니다.

성공 시 releases/FOSIM/, releases/FOSIM-exe.zip, releases/VERSION.txt를 생성합니다.

GitHub Release asset으로 배포할 파일은 FOSIM-exe.zip입니다.

9. 현재 제한과 안전 메모

중요: 현재 MVP는 CSV 기반 rule 시뮬레이터입니다. 실제 SH-2 USB/RS485 통신, Smart Manager 자동 제어, 생산 장비 설정 write, PLC 연동은 포함하지 않습니다. 예측 파형은 설정 변경 방향성을 보기 위한 참고값이며 실제 체결 결과를 보증하지 않습니다.

좋은 사용처

파형 분석 흐름 검토, 설정 변경 영향 교육, CSV 기반 POC, UI/UX 검증.

추가 검증 필요

실제 SH-2 데이터, 동일 조건 before/after 시험, 제품별 허용 토크, 현장 sigma 기준.

확장 방향

SEHAN/Modbus 통신, DOE 시험계획, ML feature predictor, 승인형 write/rollback.
